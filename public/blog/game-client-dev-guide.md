# 游戏客户端开发入门指南

## 技术栈选择

游戏客户端开发的主要技术栈分为三类：

| 方向        | 引擎/工具                  | 编程语言       |
| ----------- | --------------------------- | -------------- |
| 大厂 3A     | Unreal Engine 5             | C++            |
| 中大型项目  | Unity                       | C#             |
| 独立/手游   | Unity / Cocos Creator / Godot | C# / TS / GDScript |

## 学习路径

1. **编程基础** — C++ / C# 语法、数据结构、算法
2. **引擎入门** — 选择一款引擎，掌握编辑器操作、场景搭建
3. **脚本开发** — 用引擎脚本语言实现简单玩法逻辑
4. **渲染基础** — 管线、Shader、光照模型
5. **网络同步** — 状态同步、帧同步、延迟补偿
6. **性能优化** — Profiling、Draw Call、内存管理
7. **工程化** — 版本控制、CI/CD、打包发布

## 求职要点

- 作品集 > 学历：一个完整的 Demo 胜过千言万语
- 理解 3C（Character、Camera、Control）系统是基本功
- 算法题：LeetCode Medium 水平足够
- 关注游戏公司的校招/社招窗口
