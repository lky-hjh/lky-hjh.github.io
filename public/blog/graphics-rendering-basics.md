# 游戏图形渲染基础入门

## 渲染管线

1. **应用阶段** — CPU 准备场景数据（视锥体剔除、LOD）
2. **几何阶段** — 顶点着色器、曲面细分、几何着色器、投影变换
3. **光栅化阶段** — 三角形遍历、片段着色器
4. **输出合并** — 深度测试、模板测试、颜色混合

## 前向渲染 vs 延迟渲染

| 特性         | 前向渲染         | 延迟渲染         |
| ------------ | ---------------- | ---------------- |
| 光源数量     | 有限（<10）      | 大量（100+）     |
| 复杂度       | 低               | 高               |
| MSAA         | 原生支持         | 需额外处理       |
| 带宽消耗     | 低               | 高（GBuffer）    |

## 常见优化技巧

- 动态合批（Dynamic Batching）
- GPU Instancing
- Occlusion Culling（遮挡剔除）
- LOD（Level of Detail）
- Texture Streaming
