# 游戏网络同步技术详解

## 传输层对比

| 协议 | 特点                       | 适用场景     |
| ---- | -------------------------- | ------------ |
| TCP  | 可靠有序，延迟高           | 非实时数据   |
| UDP  | 不可靠无序，延迟低         | 实时游戏     |
| WebSocket | 基于 TCP，浏览器友好 | H5 游戏  |

## 帧同步 vs 状态同步

**帧同步（Lockstep）**
- 只同步玩家输入
- 每个客户端独立演算
- 适合 RTS / 格斗游戏
- Bug 难排查（不同步即崩溃）

**状态同步（State Sync）**
- 服务端计算，客户端表现
- 适合 FPS / MMO
- 容错性好，可热更新
- 带宽消耗较高

## 常见技术方案

- **客户端预测** — 模拟本地操作，减少感知延迟
- **插值** — 平滑显示中间状态
- **延迟补偿** — 服务端回溯时间窗口检查命中
